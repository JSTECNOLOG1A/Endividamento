# Primeiro deploy — AllDebt

O AllDebt **já está em produção** no VPS Clarity — não existe um "primeiro
deploy" pendente hoje. Para atualizar o que já está no ar, ver
[`UPDATE.md`](./UPDATE.md).

Este arquivo existe só para não deixar uma referência quebrada (o prompt
de entrega em [`PROMPT-AGENTE-DEPLOY.md`](./PROMPT-AGENTE-DEPLOY.md) o
menciona). Se um dia for necessário provisionar o AllDebt do zero em um
novo servidor, documentar aqui o passo a passo (Traefik, rede
`traefik-net`, geração do `.env.production`, etc.) — não inventar esse
fluxo sem confirmar antes com o usuário.
